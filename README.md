# نغمة | Naghma

تطبيق Android حديث لإدارة وتنزيل وتشغيل الوسائط المسموح للمستخدم بتنزيلها، مع دعم العربية وواجهة RTL.

## الحالة

المشروع في مرحلة التأسيس. سيتم بناء التطبيق تدريجياً مع الحفاظ على فصل الطبقات، وعدم إضافة أزرار وهمية أو وظائف غير منفذة.

## التقنية

- Flutter / Dart
- Material 3
- Riverpod
- Repository Pattern
- SQLite/Drift
- Download Manager
- Media3 / ExoPlayer
- C++ عبر Dart FFI للمهام الثقيلة فقط

## مبدأ مهم

مصادر المحتوى وسياسة التنزيل مصممتان كطبقتين مستقلتين، لدعم المصادر المسموح بها وإضافة سياسات الحماية لاحقاً دون إعادة بناء التطبيق بالكامل.
